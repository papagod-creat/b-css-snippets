# b-css-snippets 🎨

日常收集/沉淀的 **常用 CSS 效果片段库**——每个片段独立成文件、类名即用即贴，配套一个可运行的 demo 页。

## 片段清单

| 文件 | 内容 |
|---|---|
| `snippets/buttons.css` | 渐变按钮 / 幽灵按钮 / 按压回弹 / 加载中转圈 |
| `snippets/cards.css` | 浮起卡片 / 玻璃拟态 / 渐变流光描边 / 图片遮罩 |
| `snippets/gradients.css` | 晚霞 / 深空 / 薄荷 / 流动渐变 / 网格纸纹理 |

## 在线预览

直接打开 `demo/index.html`，或部署到任意静态托管（GitHub Pages / CF Pages 均可）。

## 用法

```html
<link rel="stylesheet" href="snippets/buttons.css">
<button class="btn-gradient">我是渐变按钮</button>
```

所有类名独立无耦合，按需挑单个片段拷走也行。
